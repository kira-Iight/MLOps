## Профиль железа по таблице курса
Выбранный профиль: **базовый**

Выбранная модель: **Qwen/Qwen3-0.6B**

**Обоснование выбора**: 
Мой MacBook Air использует Apple Silicon с MPS-ускорением. Модель Qwen3-0.6B:
- Занимает ~1.9 ГБ памяти, что комфортно для 8-16 ГБ RAM
- Показывает скорость ~31 токен/сек, что достаточно для экспериментов
- Модель 1.7B может быть медленнее на MacBook Air
- Модель 135M слишком простая для содержательных ответов

Поэтому Qwen3-0.6B — оптимальный выбор для моего железа.

## Обнаруженные дефекты и их исправление

### 1. Имя модели захардкожено в коде
- **Где найден**: `src/model.py`, `src/generate.py`, `src/bench.py`
- **Как проявлялся**: При изменении `params.yaml` модель не менялась
- **Как исправлено**: Заменил жесткие строки на чтение из `params.yaml` через `load_params()`. Теперь имя модели берется из `params["model"]["name"]`

### 2. Зависимости без версий
- **Где найден**: `pyproject.toml`
- **Как проявлялся**: Разные версии библиотек на разных машинах приводили к невоспроизводимому поведению
- **Как исправлено**: Добавил ограничения версий для всех зависимостей:
  - `torch>=2.0.0,<3.0.0`
  - `transformers>=4.36.0,<5.0.0`
  - `accelerate>=0.25.0,<1.0.0`
  - `numpy>=1.24.0,<2.0.0`
  - `pyyaml>=6.0,<7.0`
  - `psutil>=5.9.0,<6.0.0`

### 3. Неправильный замер времени
- **Где найден**: `src/bench.py`
- **Как проявлялся**: Время загрузки и генерации измерялись вместе, из-за чего `tokens/sec` были неправдоподобно малы
- **Как исправлено**: 
  - Разделил замер загрузки (`load_time`) и генерации
  - Добавил обязательный прогрев перед замерами (`warmup_runs`)
  - Теперь время генерации измеряется отдельно от времени загрузки

### 4. Недетерминированность
- **Где найден**: `params.yaml` (temperature: 0.7) и отсутствие фиксации seed
- **Как проявлялся**: Разные ответы при повторных запусках
- **Как исправлено**: 
  - Установил `temperature: 0.0` в `params.yaml` для жадного поиска
  - Добавил вызов `set_seed(params["generate"]["seed"])` в `generate.py` и `bench.py`
  - Проверил детерминизм через `diff` двух запусков

## Результаты проверки `tests/check.sh`

Все 5 проверок пройдены успешно:
1. Имя модели не захардкожено в коде

3. Генерация воспроизводима при temperature = 0
4. Зависимости зафиксированы (uv.lock и версии указаны)
5. Замеры разделены и есть прогрев

Модель Qwen3-0.6B успешно загружается и генерирует ответы на MacBook Air с использованием MPS-ускорения. Производительность составляет ~31 токен/сек при пиковом потреблении памяти ~1.9 ГБ.
